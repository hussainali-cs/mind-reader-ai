# 🧠 Mind Reader AI

An interactive mathematical mind-reading and number guessing game built with HTML, CSS and Vanilla JavaScript.

The project features two different game modes:

- 🧠 **Mind Reader** — mathematically determines the number you're thinking of.
- 🤖 **Guess My Number** — an AI-style bot attempts to find your number using binary search.

## 🧠 How the Mind Reader Works

The Mind Reader uses binary representation.

Numbers from 1 to 63 can be represented using six binary bits.

Each card represents one binary position:

```text
Card 1 → 1
Card 2 → 2
Card 3 → 4
Card 4 → 8
Card 5 → 16
Card 6 → 32
